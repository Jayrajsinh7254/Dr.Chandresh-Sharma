## Tech Stack & Features
- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System tokens, animations, responsive breakpoints), Vanilla JavaScript (ES6+)
- **CSS Framework**: Bootstrap 5.3 + Bootstrap Icons
- **Design Tokens**: Healthcare-tailored color palette (`#0B3C5D` deep clinical navy, `#2B9EB3` orthopedic teal, `#FF9F1C` action amber)
- **Features**:
  - Sticky header with associated hospital logo strip
  - Interactive hero section with doctor profile and quick booking
  - Service showcase for Knee/Hip Replacement, Spine Surgery, Arthroscopy, and Trauma Care
  - About doctor credentials & interactive vertical career timeline
  - Animated stats counters
  - Filterable orthopedic cases catalog with clinical outcome metrics
  - Real patient video testimonial preview modals & verified reviews
  - Interactive dual-location OPD schedules with Google Maps links
  - Validated appointment booking form
  - Fully responsive across desktop, laptop, tablet, and mobile with sticky bottom quick-action bar

## Running Locally
To run locally using the included lightweight HTTP server:
```bash
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## Validation Suites
- `node verify.js`: Verifies content completeness, section ordering, assets, and design token integrity.
- `node test-responsive.js`: Audits responsive breakpoints, mobile overflow, tap targets, and safe area insets.
